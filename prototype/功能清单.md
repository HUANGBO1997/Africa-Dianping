# Africa Dianping / SAVOUR 产品方案

定位：面向非洲本地用户的轻量餐饮发现与点评平台，以商家展示、菜单、口碑、WhatsApp 导流和导航构成 MVP。SAVOUR 为暂定品牌。首屏暂用阿比让及 FCFA 演示，不代表已确认上线城市、商家或定价。

## MVP 功能清单

| 端 | 功能 | 首版范围 | 当前原型 |
| --- | --- | --- | --- |
| 顾客端 | 餐厅发现 | 城市、分类、名称/区域搜索，餐厅卡片 | 单城市、搜索与分类可交互 |
| 顾客端 | 商家详情 | 介绍、图片、地址、营业时间、联系方式 | 示例数据展示，图片为食物图形占位 |
| 顾客端 | 菜单 | 菜品名称、价格、图片、简介 | 菜单名称及价格展示 |
| 顾客端 | 点评 | 查看评分和点评，登录后提交，举报与审核 | 输入校验和提交反馈；不保存、不发布 |
| 顾客端 | WhatsApp | 点击商家已核验号码，带默认询问文字跳转 | 展示跳转说明；待真实号码接入 |
| 顾客端 | 地图导航 | 使用商家坐标调用地图导航 | 展示导航说明；待真实地址/坐标接入 |
| 顾客端 | 英法双语 | 界面英语/法语切换；商家内容支持双语录入 | 主要界面可切换；部分商家分类仍为英文 |
| 商家端 | 入驻与账号 | 注册、登录、入驻申请、平台审核、店铺归属 | 入口和演示后台；认证待开发 |
| 商家端 | 店铺管理 | 编辑介绍、地址、营业时间、电话、图片 | 表单演示；不持久化 |
| 商家端 | 菜单管理 | 添加、编辑、下架菜品及价格 | 编辑表单演示；不持久化 |
| 商家端 | 点评管理 | 查看点评与回复；不可自行删差评 | 功能规划，尚未实现 |
| 商家端 | 付费置顶 | 选择周期、查看费用、申请/支付、查看状态 | 赞助位和申请反馈；未定价、无扣款 |
| 商家端 | 基础统计 | 浏览量、WhatsApp 点击、导航点击 | 静态示例指标 |
| 平台端 | 运营后台 | 审核入驻、管理商家、分类、点评及举报 | 功能规划，尚未实现 |
| 平台端 | 广告管理 | 置顶订单、排期、到期下架、赞助标识 | 首页已展示赞助标识；管理待开发 |

## 关键规则

- 置顶位必须标明“赞助”，不改变真实点评分数。
- 联系电话与地图坐标需经过商家核验，才能开启真实跳转。
- 点评应具备身份校验、反垃圾和举报审核；商家只能回复。
- 支付渠道与计费方式在确定国家、币种和收款主体后选择；首版可采用人工审核付款后上架。
- 图片、商家介绍和菜单由商家提供授权内容。
- 正式版需要账号权限、数据存储、文件上传、输入校验、隐私条款及备份。

## 页面与流程

消费者：首页 → 搜索/分类 → 商家详情 → 看菜单/点评 → WhatsApp 联系或地图导航。
商家：入驻/审核 → 店铺与菜单管理 → 置顶申请 → 平台确认支付与排期 → 赞助位展示。
运营：审核入驻与点评 → 维护商家信息 → 管理置顶订单与展示周期。

## 交付与运行

- index.html：单文件交互原型，不依赖外部资源，可下载后用浏览器打开。
- desktop.png / mobile.png / business.png：桌面、手机、商家后台预览。
- 当前交付为前端原型，没有后端、真实用户数据、真实支付或生产服务。
- 在目录内运行 `python3 -m http.server 4173` 可在本机浏览器预览；这不生成公网地址。
- 交互检查已通过：餐厅列表、搜索、详情、点评反馈、法语切换、后台入口、手机无横向溢出；浏览器未报告 JS 异常。
- 可将 index.html 上传至任意静态网站托管服务生成可分享网址；当前环境无公网部署能力，尚未部署。

## 后续开发建议

先确定首发城市和商家资料，完成顾客端、商家账号与管理后台、真实 WhatsApp/导航及数据库，再接入付费置顶。收藏、榜单、优惠券、在线点餐、配送和复杂推荐留待后续迭代。
